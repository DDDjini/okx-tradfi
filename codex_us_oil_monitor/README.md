# 美股与原油 S-28 监控

将本文件夹内容作为独立仓库根目录部署。universe.json 保存原回测筛选行与分母，口径为全期、全部确认、双向合计，TP1 先于 SL 的已判定比例至少 70%。原油包括 USO、BNO ETF 与 CL=F 连续期货观察价。

运行 python scanner.py 默认只读。python scanner.py --send 启用通知。--symbols NVDA AMD 可指定标的。本机输出 scan_output.json。配置环境变量 FEISHU_WEBHOOK、APCA_API_KEY_ID、APCA_API_SECRET_KEY。AAPL、USO 必须有 Alpaca SIP 历史数据权限，其他标的使用 Yahoo。Yahoo 和 SIP 请求失败会按标的报告并使任务失败，其余标的继续。

按完整常规交易日构造日线和前四小时/剩余时段确认，使用纽约交易日历处理夏令时及提前收盘。保留原双向与原触区规则。信号仅在确认后 48 小时内通知；历史信号不会首次上线时全部推送。CL=F 只接受完整 23 小时会话。

GitHub Actions 模板每半小时扫描，串行执行，自动回写成功通知记录。部署时把三个变量写入仓库 Secrets。后续将根据目标仓库确认默认分支、Actions 权限和实际定时运行。

飞书返回成功业务码后才记录发送。HTTP 超时或发送成功后状态提交失败仍可能导致重发，通知包含固定信号 ID 便于核对。状态文件不可随意删除。定时任务可能延迟，报告中的确认时间为行情可见时间。行情旧于最近完整美股会话时拒绝发布该标的信号。CL=F 采用四天时效上限，节假日或供应商异常须查看报告。

历史先触统计不包含限价成交与交易成本。数据截至原研究的 2026-11-10，名单未按当前行情重新筛选。实时链路需在提供 SIP 凭据后补全验收。飞书开启签名校验时，还需设置 FEISHU_SIGN_SECRET。
